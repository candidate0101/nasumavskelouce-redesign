# Na šumavské louce — redesign prototyp

Statický, responzivní prototyp modernizované úvodní stránky pro Apartmány Na šumavské louce.

## Spuštění lokálně

Stačí otevřít `index.html` v prohlížeči:

```bash
open index.html
```

Pro lokální vývoj lze použít jednoduchý server:

```bash
python3 -m http.server 8765
```

Poté otevřete `http://localhost:8765`.

## Obsah

- responzivní rozvržení pro desktop a mobil;
- informace o apartmánech, vybavení, ceníku, aktivitách a kontaktu;
- rozklikávací detaily apartmánů a zvětšení fotogalerie;
- přepínatelný ceník podle sezóny;
- formulář, který návštěvníkovi připraví e-mailovou poptávku.

Fotografie jsou načítány z původních veřejných Wix zdrojů. Jde o testovací statický prototyp; formulář nemá vlastní backend.
